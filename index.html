三步加入服务器

按下面的流程操作，几分钟就能进入方块世界。

1

申请白名单认证

加入官方 QQ 群，向管理员报备班级与游戏 ID，审核通过后由管理员加入白名单，保障校园环境安全。

2

准备对应版本客户端

安装 Java 版 Minecraft 26.3原版，确认客户端版本与服务器一致。

3

输入 IP 连接

进入「多人游戏 → 添加服务器」，填入服务器 IP，双击条目即可进入世界开始游玩。

白名单申请须知

申请方法

  1. 加入官方 QQ 群（群号见下方，可一键复制）。
  2. 在群内或@管理员（群主）报备：班级、游戏 ID。
  3. 管理员核对身份后，将你的游戏 ID 加入服务器白名单。
  4. 收到管理员“彳亍”的回复后，再启动客户端、填入服务器地址连接。

注意事项

  • 本服为离线登录，游戏 ID 就是进服时使用的昵称；报名时填写的名字必须与进服名字完全一致。
  • 中途更换昵称，需要重新找管理员报备更新白名单。
  • 白名单为人工审核，未通过前直接连接服务器会被拦截，请耐心等待回复。
  • 一个游戏 ID 对应一名玩家，请勿借用、共用他人 ID。
